# VeylOps — Discord Toolkit

![Platforms](https://img.shields.io/badge/platform-Windows%20%7C%20Android%20%7C%20Web-7c3aed)
![Plans](https://img.shields.io/badge/plans-FREE%20%26%20PRO-c026d3)

Your Discord control center — presence, streams, badges and profile, all in one modern app.
**Windows · Android · Web** — https://www.veylops.it

## Features
| | |
|---|---|
| **Rich Presence** | Show a game, custom status or Spotify track; platform spoofing (mobile, console, VR) |
| **Always-on presence & voice** (PRO) | Stay online even with the app closed or the PC off — it runs in the cloud |
| **Persistent Go Live** | Streaming hours straight from your profile badge |
| **Badge Maximizer** | Game Variety & Playtime badges, with a safety cap and cooldown |
| **Quests & Games** | Complete Discord quests and manage the games catalog with favorites |
| **Voice Auto-Join** | Hop into voice with multiple accounts via a quick picker |
| **Secure account** | Change & recover your password with an email OTP |
| **Command Palette** | Everything a Ctrl + K away |

## Download
Get the latest Windows installer and Android APK from the [Releases](https://github.com/kemithereal/veylops-toolkit-discord/releases) page, or from https://www.veylops.it.

Android note: the APK is debug-signed. Coming from a version older than 1.51.0? Uninstall the old app first.

## FREE vs PRO
FREE — core presence, limited quests & badges, single account.
PRO — always-on cloud presence & voice, persistent Go Live, higher caps, multi-account.
